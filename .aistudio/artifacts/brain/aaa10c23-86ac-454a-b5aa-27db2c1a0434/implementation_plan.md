# خطة الإصلاح الشاملة لاستوديو الدبلجة: دمج MP4، تصحيح البوت، وجدول الشخصيات

خطة معمارية شاملة لحل جميع المشكلات الموضحة في تقرير المراجعة الفنية، وتلبية القرارات المؤكدة من المستخدم:
1. تصدير ملف فيديو MP4 حقيقي مدمج بالكامل بين الصورة والصوت المدبلج الجديد وليس مجرد ملف صوت WAV.
2. حل مشكلة تعطل البوت وإظهار "فشل فقط"، بتوفير نقطة نهاية خادم لـ Gemini AI (`/api/gemini/bot`)، وتشخيص مفتاح `GEMINI_API_KEY`، مع رسائل خطأ صريحة وواضحة ترشد المستخدم بدلاً من الفشل الصامت.
3. إضافة جدول مرئي تفاعلي لربط وتوزيع أصوات الشخصيات (Speaker-to-Voice Mapping Table) حسب الجنس والنبرة (بنت ← سلمى، ولد ← شاكر، وحش ← حامد، نظام ← حمدان).
4. تعزيز محرك فصل الصوت الهجين (Hybrid AI Audio Separation) مع محرك محلي فائق السرعة وبدون تكلفة أو مفاتيح خارجية.

### User Review & Critical Decisions

> [!IMPORTANT]
> تم تأكيد القرارات التالية بناءً على إجاباتك:
> - **مشكلة البوت**: البوت حالياً يعطي "فشل فقط" لغياب الـ API route الخاص بـ Gemini AI ولعدم وجود توضيح لحالة المفتاح في البيئة. سنقوم ببرمجة بوت المخرج الذكي (`/api/gemini/bot`) مع فحص بيئة العمل وعرض رسائل خطأ واضحة ومفيدة.
> - **مخرجات الفيديو**: إنتاج وتنزيل ملف فيديو MP4 كامل مدمج (`-map 0:v:0 -map 1:a:0 -c:v copy -c:a aac`) بالصوت والصورة، مع زر تحميل MP4 مباشر.
> - **فصل الصوت والشخصيات**: اعتماد محرك فصل هجين ومجاني لا يتطلب دفع اشتراكات، مع بناء جدول تعيين الأصوات للممثلين والشخصيات في واجهة التطبيق.

---

### 1. Overview & Core Concept

- **What It Does**:
  1. **محرك دمج الفيديو الحقيقي (Real MP4 Muxer)**: يدمج إطارات الفيديو الأصلية مع مسار الصوت الماستر (الموسيقى المعزولة + أصوات الدبلجة المصرية + المؤثرات) وينتج فيديو MP4 جاهز للمشاهدة والتنزيل.
  2. **بوت المخرج الذكي (AI Dubbing Director Bot)**: بوت مدمج داخل الاستوديو يستخدم `@google/genai` (موديل `gemini-3.8-flash`) لمساعدة المخرج في كتابة وتعديل حوارات الأنمي باللهجة المصرية، مع واجهة تشخيصية صريحة توضح حالة الاتصال ومفتاح `GEMINI_API_KEY`.
  3. **جدول تعيين أصوات الشخصيات (Character Voice Mapping)**: جدول متكامل يربط كل شخصية في السيناريو (مثل: سيف، سارة، كمال، الوحش، النظام) بنموذج الصوت المناسب مع استماع للمعاينة، وضبط حدة النبرة (Pitch) والسرعة (Rate).
  4. **فصل الصوت الهجين**: إبقاء مسار الموسيقى والمؤثرات فقط (BGM Stem) وكتم الحوار الأصلي تماماً لمنع تسرب الأصوات اليابانية.

### 2. User Experience & Visual Design

- **Key User Flows**:
  1. **التعامل مع البوت الذكي (AI Bot Assistant)**:
     - يمكن للمستخدم فتح نافذة "مساعد المخرج الذكي" لكتابة أو ترجمة أي مشهد إلى حوار مصري كوميدي أو أكشن متقن.
     - إذا كان مفتاح البيئة غير متاح على السيرفر، تظهر رسالة إرشادية دقيقة: "يرجى تعيين GEMINI_API_KEY في إعدادات البيئة".
  2. **توزيع أصوات الشخصيات (Voice Mapping Tab & Modal)**:
     - جدول يعرض الشخصيات المكتشفة في السيناريو.
     - اختيار الصوت لكل ممثل (شاكر - شاب بطل / سلمى - فتاة / حامد - عملاق / حمدان - نظام وروبوت).
     - معاينة كل صوت بنقرة واحدة قبل التوليد.
  3. **الريندر وتنزيل فيديو MP4 كامل**:
     - عند انتهاء الريندر، تعرض النافذة مشغل فيديو MP4 المدمج مع زر بارز: "تحميل الفيديو الكامل المدبلج (MP4)".

- **Visual Identity & Theme**:
  - استوديو داكن راقٍ (`#0B0F19`) بألوان إشارات واضحة: الأخضر للنجاح والجاهزية، والكهرماني للإشعارات الفنية.
  - عدم استخدام بطاقات متداخلة أو حواف بارزة زائدة، واستخدام خطوط واضحة وأزرار بأبعاد قياسية.

---

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: دمج الفيديو بالخادم عبر FFmpeg ومحاكاة المعاينة بالمتصفح**:
  - *Chosen Approach*: استخدام أمر FFmpeg فائق السرعة بدون إعادة تشفير الإطارات (`-c:v copy -c:a aac`) لإنتاج MP4 في أجزاء من الثانية، وتوفير تحميل MP4 مباشر.
  - *Why*: لأن تصدير مجرد صوت WAV يخيّب أمل المستخدم الذي ينتظر فيديو كامل متزامن.
- **Decision 2: إرسال أخطاء البوت الصريحة**:
  - *Chosen Approach*: منع الفشل الصامت نهائياً. كل استجابة من `/api/gemini/bot` ترجع إما النتيجة أو تفاصيل سبب المشكلة وكيفية حلها.

- **Files to Add / Update**:
  1. `.env.example`: تعريف المتغيرات البيئية مثل `GEMINI_API_KEY`.
  2. `/app/api/gemini/bot/route.ts`: نقطة نهاية سيرفر لـ Gemini SDK للتعامل مع طلبات البوت وتقديم رسائل خطأ واضحة.
