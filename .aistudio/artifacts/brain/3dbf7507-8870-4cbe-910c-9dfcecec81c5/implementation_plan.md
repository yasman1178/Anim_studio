# خطة العمل: تطوير محرك الاستخراج والتنظيف الذكي لملفات سيناريو JSON

## 1. تحليل المشكلة الجذرية
- خطأ `SyntaxError: Unexpected non-whitespace character after JSON at position 10011 (line 299 column 2)` يحدث لأن ملف الـ JSON المصدر من منصات الذكاء الاصطناعي (مثل NotebookLM أو ChatGPT أو Gemini) يحتوي على شروح أو وسوم ماركداون (مثل ` ``` `) أو تعليقات بعد انتهاء كائن الـ JSON الصحيح (عند الموضع 10010).
- الاعتماد على `JSON.parse` الافتراضي في المتصفح يفشل فوراً عند وجود أي حرف غير فراغي بعد القوس الختامي `}`.

---

## 2. خطوات التنفيذ

### المرحلة 1: بناء محرك `extractAndParseResilientJson`
- إنشاء دالة متقدمة وقوية لمعالجة وتنظيف نصوص الـ JSON في `lib/validate-json.ts`:
  1. **إزالة وسوم الماركداون والزوائد**: تنظيف البدايات والنهايات (مثل ```` ```json ```` و ```` ``` ````) ومحارف BOM الخفية (`\uFEFF`) والمسافات الصفرية.
  2. **خوارزمية موازنة الأقواس (Bracket Balancing Scanner)**:
     - تحديد أول قوس بداية `{` أو `[`.
     - تتبع عمق الأقواس بدقة متناهية مع مراعاة النصوص المقتبسة والأحرف المهربة (`\"` و `\\`).
     - تحديد نقطة نهاية الكائن الفعلي بالضبط واقتطاعه وتجاهل ما بعده من شروح وملاحظات.
  3. **معالجة الفواصل الزائدة (Trailing Commas)**: تنظيف الفواصل الزائدة قبل الأقواس الختامية `}` أو `]`.
  4. **دعم الكائنات المتتالية (Multi-Object Merge)**: إذا كان الملف يحتوي على كائنات منفصلة تباعاً، دمجها في كائن سيناريو موحد متكامل.

### المرحلة 2: تحديث واجهة رفع وتعديل السيناريو في `ProjectSetup.tsx`
- استبدال `JSON.parse` المباشر في دالتي:
  - `handleJsonUpload`: قراءة الملف وتمريره عبر المحرك الذكي.
  - `applyJsonEdits`: تطبيق التعديلات من المحرر النصي المباشر.
- إضافة إشعار مرئي يطمئن المستخدم عند إزالة الزوائد والشروح آلياً:
  `«تم استخراج كائن السيناريو وتجاوز وسوم الذكاء الاصطناعي والزوائد بنجاح!»`.
- إضافة زر **«إصلاح وتنظيف آلي»** في نافذة محرر الكود المباشر لتنسيق وإصلاح الـ JSON بنقرة واحدة.

### المرحلة 3: التوثيق والاختبار والتحقق
- تشغيل اختبارات التحقق من بناء المشروع `compile_applet` و `lint_applet`.
- اختبار حالات:
  - ملف ينتهي بوسم ماركداون ` ``` `.
  - ملف يضم شروحاً وملاحظات باللغة العربية بعد نهاية الكود.
  - ملف يحتوي فواصل زائدة أو مسافات خفية.
