# ترقية Anime Dub Studio: دعم مخطط v18، محرك المؤثرات الصوتية Web Audio، مسار /api/media وتصميم الموبايل الشامل

ترقية متكاملة لمنظومة دبلجة الأنمي والشورتس لقناة «محب أنمي»، تشمل ربط مسار تخزين الوسائط السحابي `/api/media` ودعم مخطط JSON Schema v18 الاحترافي لسلسلة "حكاية سيف"، مع محرك توليد المؤثرات الصوتية التزامني الفوري عبر Web Audio API، وتطوير واجهة مستخدم متجاوبة للهواتف المحمولة تعتمد شريط تنقل سفلي مريح وشاشة عرض عمودية 9:16.

> [!IMPORTANT]
> ### القرارات الحاسمة المؤكدة مع المستخدم
> - **مسار الوسائط وتخزين Blob**: تضمين محاكي Vercel Blob سحابي متوافق مع Next.js وربطه بالمشروع عبر `/api/media` بحيث يعيد `{ ok: true }` عند الفحص، مع دعم رفع وتنزيل الملفات العامة.
> - **المؤثرات الصوتية (SFX) ومخطط v18**: بناء محرك توليف فوري للمؤثرات الترددية والسينمائية (Sub Boom, Roar, Swoosh, Glitch, Heartbeat) باستخدام Web Audio API للعمل محليًا وتزامنيًا مع الخط الزمني ونظام Beats الجديد بدون ملفات خارجية ثقيلة.
> - **واجهة الموبايل (Mobile UX)**: تخصيص شريط تنقل سفلي ثابت (Fixed Bottom Tab Bar) بارتفاع مريح وأزرار لمس $\ge 44\text{px}$، مع نافذة معاينة سينمائية رأسية 9:16 متطابقة مع YouTube Shorts وReels.

---

## 1. نظرة عامة والهدف الأساسي (Overview & Core Concept)

- **ماذا يقدم التحديث**: يتيح لصناع محتوى الأنمي ودبلجة الشورتس استيراد ملفات سيناريو JSON وفق مواصفة **v18 الموحدة** (سلسلة حكاية سيف)، والتي تنظم الأصوات بمعرّفات قياسية (`narrator`, `tension`, `excited`, `sad`, `beast`, `system`)، وتضبط إيقاع اللقطات البصرية بمصفوفة `beats` كل 2.5-3 ثوانٍ، وتتيح تشغيل مؤثرات صوتية متعددة لكل لقطة عبر محرك صوت متقدم، وربط منصة التخزين لنشر الفيديوهات وتصديرها.
- **الجمهور المستهدف**: قناة «محب أنمي» وصناع محتوى الدبلجة التلخيصية باللهجة المصرية، مع التركيز على الاستخدام السلس من الهواتف المحمولة وأجهزة سطح المكتب على حد سواء.
- **القيمة المضافة**: التخلص التام من أخطاء التحقق في السيناريوهات، وإلغاء الحاجة لتحميل ملفات SFX ضخمة عبر توليدها برمجيًا، وسرعة وسلاسة تامة في العمل عبر الهاتف مع دعم كامل لنسبة العرض 9:16.

## 2. تجربة المستخدم والتصميم البصري (User Experience & Visual Design)

### مسار رحلة المستخدم (User Flow)
1. **الفتح والتهيئة**: عند فتح التطبيق، يفحص مسار `/api/media` حالة التخزين، ويتيح تحميل مشروع جديد أو اختبار مشروع تجريبي متوافق 100% مع مخطط v18.
2. **فحص ومراجعة السيناريو**: محرك التحقق يفحص تلقائيًا بنية الجيسون الجديدة: `character_bible`، `beats`، أصوات Edge-TTS، وضوابط التشكيل وغياب الشرطات داخل الحوار.
3. **المعاينة التفاعلية والتأثيرات**: الخط الزمني وشاشة العرض 9:16 تشغل الشوت مع حركات الكاميرا (`zoom_in`, `pan`, `shake`) وتولد المؤثر الصوتي الافتتاحي (`Sub Boom Impact`) والمؤثرات اللاحقة لحظيًا بدقة الميلي ثانية.
4. **توليد الأصوات والحفظ**: تحويل نصوص الحوار لأصوات مصرية متطابقة مع قوالب v18 وحفظ الاستجابات في Blob ومخزن الوسائط.

### الهوية البصرية وتصميم الموبايل (Mobile Design & Visual Identity)
- **شريط التنقل السفلي للهواتف (Bottom Navigation)**: شريط ثابت سفلي أنيق بتأثير زجاجي معتم (`bg-slate-900/95 backdrop-blur-md border-t border-slate-800`) بارتفاع محكم يحقق شرط الـ 15% كحد أقصى لارتفاع العناصر الثابتة، مع 5 وجهات واضحة: المشروع، عزل الصوت، الدبلجة، الخط الزمني، والنشر.
- **مساحات اللمس المريحة (Ergonomic Touch Targets)**: أزرار تحكم بارتفاع $\ge 48\text{px}$، وتباعد مريح يمنع الضغط الخاطئ أثناء استخدام إصبع الإبهام على الموبايل.
- **عارض الشورتس الرأسي 9:16**: حاوية معاينة رأسية ذات أبعاد مدروسة تحاكي واجهة تيك توك ويوتيوب شورتس بالكامل، مع إبراز الكابشنز المتحركة وتوهجات الهالات البصرية (VFX Auras).
- **ألوان هادئة ومتباينة (60-30-10 Palette)**:
  - 60% خلفية داكنة فائقة الفخامة: `#0B0F19` (Slate Dark Canvas).
  - 30% بطاقات وعناصر سطحية: `#131B2E` مع خطوط فصل رفيعة `border-slate-800`.
  - 10% لهجات تفاعلية حيوية: لون التوت والنيون الوردي `#E11D48` والأزرق السيان الفيروزي `#06B6D4` لـ CTAs ومؤشرات التشغيل.

## 3. القرارات الهندسية والمفاضلات الفنية (Key Decisions & Trade-Offs)

### أ. مسار `/api/media` وتخزين Vercel Blob
- **القرار المتخذ**: إنشاء مسار خادم متكامل `/app/api/media/route.ts` و`/app/api/blob/route.ts` مع محاكي Blob تخزيني يدعم:
  - الرد على طلبات GET بـ `{ ok: true, status: "ready", storage: "blob", count: ... }` كما طلب المستخدم حرفيًا.
  - دعم رفع وتنزيل الملفات وقراءة الـ Blobs بنوع `public`.
  - إضافة ملف سكربت تنفيذي `scripts/setup-storage.mjs` لتهيئة وربط الـ Blob والتأكد من استجابة `/api/media`.

### ب. محرك المؤثرات الصوتية الفوري (Web Audio API Synthesizer)
- **القرار المتخذ**: استبدال الاعتماد على ملفات MP3 خارجية مفقودة بمحرك توليد ترددات وتصادمات صوتية آنية باستخدام `AudioContext`:
  - `Sub Boom Impact`: هبوط ترددي أسي من 80Hz إلى 18Hz مع ضغط ديناميكي، وهو المؤثر المطلوب افتتاحيًا عند `trigger_sec = 0.0`.
  - `Giant Monster Roar`: مذبذبات صوتية ثلاثية (Sawtooth/Square) مدمجة مع فلتر Bandpass متحرك ومستوى تشويش.
  - `Swoosh / Whip`: تصفية الضوضاء البيضاء مع غلاف اتساع سريع لصوت الحركة والانتقالات.
  - `Heartbeat Slow`: نبضتان جيبيتان منخفضتان (60Hz / 42Hz) للحظات الشجن والصعبانيات.
  - `Glitch / Tech Shock`: رنين متقطع سريع لأصوات النظام والتعاويذ السحرية.

### ج. دعم كامل لمخطط v18 وقواعد Edge-TTS
- **القرار المتخذ**: تحديث `lib/validate-json.ts` وعينات المشاريع لدعم الحقول الجديدة:
  - `character_bible` واستخدامه للتحقق من أسماء الشخصيات في المشاهد.
  - `beats` لكل شوت والتأكد من وقوعها كل 2.5-3 ثوانٍ.
  - قائمة `sound_design.sfx` الجديدة ككائنات `{ sfx_name, sfx_volume_percent, sfx_trigger_sec }`.
  - ترجمة قوالب `vocal_cue` إلى قيم Edge-TTS المحددة في الجدول (Shakir / Hamed / Hamdan) مع ضبط الـ pitch بالـ Hz.

### خطة تنفيذ الملفات:
1. **إنشاء مسار وتخزين الوسائط**:
   - كتابة `/app/api/media/route.ts` ليعيد `{ ok: true, status: "ready", storage: "blob", ... }` ويدير رفع الوسائط.
   - كتابة `/app/api/blob/route.ts` لخدمة ملفات البينات وربط الـ Blob العام.
   - إنشاء سكربت `scripts/setup-storage.mjs` لربط وفحص التخزين.
2. **محرك المؤثرات الصوتية الفوري (SFX Engine)**:
   - إنشاء `/lib/sfx-synthesizer.ts` لتوليد المؤثرات التزامنية بدون أي اعتماديات خارجية.
   - ربطه مع مشغل الفيديو والخط الزمني ليعمل تلقائيًا عند وصول مؤشر الوقت لكل `sfx_trigger_sec`.
3. **مخطط v18 والتحقق والمعجم**:
   - تحديث `/lib/validate-json.ts` لدعم schema v18 (`character_bible`, `beats`, `sfx` array, presets).
   - تحديث `/lib/sample-data.ts` بمشروع تجريبي عالي الجودة متوافق بنسبة 100% مع قصة "سيف في المعبد".
   - تحديث `/app/api/tts/route.ts` لدعم معرّفات الأصوات وضبط الـ Hz للطبقة الصوتية.
4. **تطوير واجهة الموبايل المتجاوبة**:
   - إضافة شريط التنقل السفلي المريح (Bottom Navigation Bar) للهواتف في `components/BottomNav.tsx`.
   - تحسين `components/VideoCanvas.tsx` و`components/StudioTimeline.tsx` و`app/page.tsx` للعمل باحترافية على شاشات الهواتف مع تبديل أوضاع 9:16 بضغطة زر.
   - التحقق من معايير التصميم وبناء التطبيق بدون أي أخطاء.
