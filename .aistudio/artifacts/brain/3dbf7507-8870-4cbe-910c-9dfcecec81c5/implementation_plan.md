# خطة الإصلاح الشاملة لمحرك الصوت والدبلجة والإنتاج الحقيقي (Anime Dub Studio)

خطة هندسية تفصيلية لمعالجة المشاكل الجذرية التي أشار إليها المستخدم بدقة: فك تشفير صوت MP4 عبر معالج حقيقي (FFmpeg Server Proxy و Web Audio)، وشفافية عزل مسارات الأنمي، وإلغاء كتم الحوار التلقائي، وإصلاح Edge-TTS لتشمل الراوي وتخصيص أصوات سارة وكمال مع التنبيه الصريح عند الفشل، وتحويل زر الإنتاج إلى محرك حقيقي يولد الأصوات الناقصة ويدمج المسارات الصوتية بالكامل.

> [!IMPORTANT]
> ### القرارات الحاسمة المؤكدة مع المستخدم (Phase 1 Confirmation)
> 1. **إدخال السيناريو**: الاعتماد على استيراد ورفع ملفات سيناريو JSON الجاهزة v18 مع تحسين مشغل الوسائط، دون حاجة لتفريغ آلي إضافي عبر Gemini.
> 2. **فك تشفير صوت MP4 وعزل القنوات**: فك تشفير حقيقي للصوت من حاويات الفيديو (عبر مسار `/api/extract-audio` المدعوم بـ FFmpeg المثبت على الخادم مع دعم الـ AudioContext المحلي)، وتوضيح حالة وجودة عزل القنوات بشفافية هندسية كاملة دون ادعاءات وهمية.
> 3. **زر الإنتاج النهائي (Render Engine)**: تحويل زر الإنتاج إلى مسار تنفيذ حقيقي يفحص كافة لقطات المشروع، ويولد آلياً عبر `/api/tts` أي سطر حوار أو تعليق راوٍ لم يُولد بعد، ثم يدمج المسارات في ملف ماستر نهائي متزامن مع شاشة المعاينة وإمكانية تحميله فوراً.

## 1. تحليل المشاكل الجذرية والحلول الهندسية

### 1.1 مشكلة تعذر فك تشفير صوت الفيديو MP4 في `lib/audio-separation.ts`
- **السبب الجذري**: الدالة في المحاولة الأولى تنادي `decodeAudioData` على مصفوفة بايتات ملف الـ MP4 بالكامل، وهذا يفشل في معظم المتصفحات لأن الحاوية MP4 تتطلب Demuxer لاستخراج تيار الـ AAC/PCM. وفي المحاولة الثانية (سطر 105-107)، كانت الكود ينادي نفس الدالة `decodeAudioData` مجدداً على نفس بايتات الـ MP4 دون فك حقيقي.
- **الحل الجذري**:
  - إنشاء مسار خادم مخصص `/app/api/extract-audio/route.ts` يستقبل ملف الفيديو (أو المسار المخزن) ويستخدم أداة `ffmpeg` المثبتة بالفعل في النظام (`/usr/bin/ffmpeg`) لاستخراج تيار صوتي خام بصيغة WAV PCM (16-bit, 44.1kHz, Stereo).
  - في واجهة المتصفح: محاولة القراءة السريعة عبر `AudioContext` للملفات الصوتية المباشرة، وإذا كان الملف فيديو MP4/WebM، يتم إرساله فوراً إلى مسار الفك الحقيقي `/api/extract-audio`، فيعود ملف WAV نقي يُفكك في الذاكرة بنجاح 100%.

### 1.2 شفافية عزل الحوار والمؤثرات وحل كتم الصوت الافتراضي
- **المشكلة**: استخدام معادلة الطور والوسط/الجانب (Mid/Side) لا يفصل كلام الأنمي عن ضربات الأكشن بكفاءة لأن كليهما في المنتصف، وزر العينة كان صوتاً اصطناعياً. كما أن `VocalSeparator.tsx` كان يضع `isDialogueMuted = true` والوضع `instrumental` مما يجعل المستخدم يسمع صمتاً تلقائياً ويظن أن النظام لا يعمل.
- **الحل الجذري**:
  - إلغاء كتم الحوار التلقائي: جعل الحالة الافتراضية `isDialogueMuted = false` والوضع الأولي للمشغل متوازناً بين الموسيقى والحوار (`dialogueVolume = 0.8` و `musicVolume = 1.0`).
  - الشفافية الهندسية: إزالة رسائل النجاح الزائفة، واستبدالها بوصف تقني شفاف (DSP Center-Channel Isolation) مع مؤشر دقيق لجودة العزل، وتوضيح أن الأنمي ذو الضربات المتداخلة يحتاج خفض الحوار الأصلي واستبداله بالدبلجة المصرية المولدة.

### 1.3 محرك الدبلجة Edge-TTS في `components/VoiceGenerator.tsx`
- **المشاكل**:
  1. زر «توليد الكل» كان يمر فقط على `shot.dialogue` ويتجاهل تماماً نصوص الراوي `shot.voiceover_egyptian`.
  2. ثبات الصوت على نبرة واحدة `ar-EG-ShakirNeural` وإلغاء تخصيص نبرات الشخصيات (سارة يجب أن تكون `ar-EG-SalmaNeural`، وكمال/الوحش `ar-SA-HamedNeural` مع طبقة عميقة).
  3. عند حدوث خطأ في الاتصال أو استجابة Edge-TTS، كان التطبيق يهرب بصمت إلى صوت المتصفح الآلي الرديء دون إخبار المستخدم بفشل خادم Edge.
- **الحل الجذري**:
  - تحديث `generateAllVoices` ليشمل توليد أصوات الراوي `voiceover_egyptian` لكل لقطة بالتوازي مع سطور الحوار.
  - تطبيق خريطة أصوات الشخصيات الرسمية بدقة:
    - **سيف / الراوي**: `ar-EG-ShakirNeural` (نبرة شابة بطولية).
    - **سارة**: `ar-EG-SalmaNeural` (نبرة نسائية مصرية نقية).
    - **كمال / الوحش**: `ar-SA-HamedNeural` مع طبقة صوتية خشنة (`pitch: -15Hz` و `rate: -5%`).
  - إيقاف الهروب الصامت: إذا فشل خادم Edge-TTS أو أعاد خطأ، يتم إيقاف العملية وعرض رسالة خطأ واضحة باللون الأحمر توضح سبب فشل السيرفر وتطلب إعادة المحاولة.

### 1.4 زر الإنتاج النهائي الحقيقي في `app/page.tsx`
- **المشكلة**: دالة `handleRenderClick` كانت تنتظر 2.5 ثانية عبر مؤقت وهمي دون عمل أي شيء.
- **الحل الجذري**:
  - تحويل الدالة إلى مسار عمل حقيقي كامل:
    1. فحص جميع لقطات المشروع: التحقق من وجود ملف صوتي `audio_url` لكل سطر حوار وكل تعليق راوٍ.
    2. توليد أي مقطع صوتي مفقود تلقائياً عبر `/api/tts` وتحديث حالة المشروع.
    3. تركيب ودمج المسارات الصوتية زمنياً عبر `OfflineAudioContext` (أو مسار الدمج النهائي): وضع كل مقطع صوتي عند توقيته الدقيق `trigger_sec` مع دمج الموسيقى الخلفية والمؤثرات الصوتية SFX.
    4. تصدير ملف ماستر صوتي مدمج كامل `master_dubbed_audio.wav` وربطه بالمشغل وتوفير زر تنزيل مباشر له.

### 1.5 وضوح مصادر الفيديو والمدة الزمنية
- **المشكلة**: تثبيت مدة الفيديو على 180 ثانية لروابط يوتيوب دون تنبيه للمستخدم بأن الصوت الحقيقي يتطلب ملف MP4 محلي.
- **الحل الجذري**:
  - عرض تنبيه بارز في واجهة `ProjectSetup`: "روابط يوتيوب مخصصة للمعاينة البصرية فقط. لمعالجة واستخراج الصوت الحقيقي وتركيب الدبلجة، يرجى رفع ملف الفيديو MP4 من جهازك".
  - إتاحة تحديد مدة المشهد بدقة وقراءة المدة الفعلية عند رفع الملف.

## 2. البنية التقنية ومسار تدفق البيانات (Architecture Diagram)

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Anime Dub Studio V18 Architecture               │
├────────────────────────────────────────────────────────────────────────┤
│ 1. Media Input & Extraction:                                           │
│    [ User MP4 Video ] ────► [ /api/extract-audio (FFmpeg Engine) ]    │
│                                           │                            │
│                                           ▼                            │
│                               [ Clean Stereo WAV Audio ]               │
│                                           │                            │
│                                           ▼                            │
│ 2. Audio Processing & Mixer:                                           │
│    [ Web Audio Context ] ◄──► [ Vocal & Instrumental Mixer ]           │
│    (Unmuted default, real-time volume controls, transparent DSP stats)  │
│                                                                        │
│ 3. Voice Synthesis Engine:                                             │
│    [ v18 Project Shots ] ────► [ /api/tts (Edge-TTS) ]                 │
│    - Dialogue Lines (Sara: Salma, Kamal: Hamed, Seif: Shakir)          │
│    - Narrator Voiceovers (voiceover_egyptian)                          │
│    - Strict Error Handling (No silent robotic fallback)                │
│                                                                        │
│ 4. Master Render Engine:                                               │
│    [ User clicks "إنتاج ومعاينة الشورتس" ]                             │
│         │                                                              │
│         ├─► 1. Auto-generate any missing TTS clips                     │
│         ├─► 2. Align clips at trigger_sec on timeline                  │
│         ├─► 3. Mix with BGM & Web Audio SFX                            │
│         └─► 4. Output master_dubbed_audio.wav & enable playback/dl     │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. خطة التعديل على الملفات (Detailed File Changes)

1. **`app/api/extract-audio/route.ts` (جديد)**:
   - مسار خادم يستقبل الـ FormData التي تحتوي على ملف الفيديو MP4/WebM.
   - يستدعي أمر FFmpeg الحقيقي لاستخراج الصوت:
     `ffmpeg -i [input] -vn -acodec pcm_s16le -ar 44100 -ac 2 [output].wav`
   - يعيد تيار الـ WAV المستخرج إلى المتصفح مع ترويسة `audio/wav`.

2. **`lib/audio-separation.ts`**:
   - تعديل `decodeAudioFromMediaBlob`: استبدال المحاولة الثانية المكررة بالاتصال المباشر بـ `/api/extract-audio` عند التعامل مع ملفات الفيديو، لضمان استخراج الصوت الحقيقي بنجاح تام.
   - تحسين توضيح مخرجات العزل وتزويد واجهة المستخدم بمعلومات صادقة عن طبيعة فصل القنوات.

3. **`components/VocalSeparator.tsx`**:
   - جعل الحوار غير مكتوم افتراضياً (`isDialogueMuted = false`).
   - تعيين وضع الاستماع الافتراضي على الاستماع المتوازن، مع تمكين المستخدم من التحكم الفوري في مستوى صوت الحوار والموسيقى.

4. **`components/VoiceGenerator.tsx`**:
   - ترقية دالة `generateAllVoices` لتوليد كل من `dialogue` و `voiceover_egyptian`.
   - ضبط النماذج الصوتية: سارة تستخدم `ar-EG-SalmaNeural`، كمال يستخدم `ar-SA-HamedNeural` مع طبقة صوتية خشنة، والراوي/سيف يستخدم `ar-EG-ShakirNeural`.
   - إزالة الهروب الصامت `speakNative` عند فشل Edge-TTS، واستبداله بعرض رسالة خطأ صريحة.

5. **`app/page.tsx` و `components/TopBar.tsx`**:
   - إعادة كتابة دالة `handleRenderClick`:
     - فحص كل المقاطع الصوتية، وتوليد المقاطع الناقصة عبر استدعاءات `/api/tts`.
     - دمج المسارات عبر `OfflineAudioContext` في ملف صوتي ماستر متكامل.
     - ربط الملف النهائي بشاشة العرض وإظهار رسالة النجاح مع زر تنزيل الملف الصوتي النهائي.
   - إبراز تنبيهات الفيديو في `ProjectSetup`.
