# خطة تنفيذ خط أنابيب الدبلجة وفصل الصوت التلقائي المتكامل (1-Click Anime Dub Pipeline)

بناءً على متطلباتك، سنقوم بحل المشكلتين وتطوير خط أنابيب متكامل بضغطة زر واحدة:
1. **فصل الصوت عن الموسيقى للفيديو المرفوع** بنظام مرن يفك شفرة الصوت مباشرة دون مشاكل حدود حجم الملفات، مع تحييد الحوار البشري والإبقاء على الموسيقى التصويرية (BGM).
2. **تنفيذ الدبلجة التلقائية لكافة مقاطع الحوار والراوي المحددة في ملف الجيسون** عبر خادم Edge-TTS ومزامنتها على الخط الزمني بدقة، ثم إنتاج وتصدير **فيديو نهائي مدبلج (MP4)** و**مسار صوتي ماستر (WAV)**.

---

## 1. محرك استخراج وفصل الصوت من الفيديو (Audio Extraction & Vocal Separation)
- **استخراج مرن ومباشر للصوت:**
  - دعم استخراج الصوت مباشرة داخل المتصفح عبر Web Audio API وعنصر الفيديو `HTMLVideoElement` (فك تشفير صوت الفيديو محلياً دون الحاجة لرفعه عبر الشبكة عند كبر حجمه)، مع الإبقاء على نقطة النهاية السريعة `/api/extract-audio` عبر FFmpeg للملفات المدعومة.
- **خوارزمية فصل الصوت وعزل الحوار (Vocal & BGM Isolation):**
  - تطبيق فلترة طيفية متقدمة (Multi-band Mid/Side Spectral Attenuation) مع الحفاظ على ترددات البيس (Sub-bass) وترددات المؤثرات المحيطية للأنمي.
  - خفض/كتم صوت الممثلين الأصليين وتجهيز مسار الموسيقى النظيف (BGM) ليكون قاعدة لتركيب الدبلجة المصرية فوقه مع ميزة الـ Auto-Ducking (خفض الموسيقى تلقائياً عند حديث الشخصيات).

---

## 2. محرك قراءة الـ JSON والتوليد التلقائي للدبلجة (Batch Edge-TTS Dubbing)
- **قراءة المخطط الزمني بالكامل:**
  - استخراج كافة أسطر الحوار (`dialogue`) وصوت الراوي (`voiceover_egyptian`) من كل لقطة (`shot`) في ملف السيناريو JSON.
- **توليد الأصوات المصرية المتزامنة:**
  - تعيين نبرة الصوت المناسبة لكل شخصية آلياً (سيف: `ar-EG-ShakirNeural`، سارة: `ar-EG-SalmaNeural`، الوحوش/العمالقة: `ar-SA-HamedNeural`، النظام: `ar-AE-HamdanNeural`).
  - إرسال دفعات التوليد بالتوازي/التتابع عبر `/api/tts` وتخزين ملفات الصوت الناتجة فوراً في الذاكرة المحلية IndexedDB وتحديث كائن المشروع.
  - تطبيق توقيت البدء المحدد في الجيسون (`trigger_sec` و `duration_sec`) لكل لقطة لضمان الدبلجة المتزامنة.

---

## 3. محرك دمج وإنتاج الفيديو النهائي المدبلج (MP4 Muxer & Master Audio Mixer)
- **مسار ماستر صوتي (WAV):**
  - دمج مسار الموسيقى المعزولة (BGM) مع مقاطع الدبلجة المصرية المولدة والمؤثرات الصوتية (SFX) بدقة 44.1kHz ستيريو.
- **إنتاج فيديو MP4 مدبلج:**
  - إنشاء نقطة نهاية `/api/mux-video` مدعومة بـ FFmpeg في الخادم، وأيضاً مسار دمج ميديا محلي عبر `MediaStreamDestination` / `MediaRecorder` داخل المتصفح، لدمج صورة الفيديو الأصلي مع المسار الصوتي المدبلج الجديد.
  - استبدال الصوت الأصلي بالصوت المدبلج الجديد وتصدير ملف `dubbed_video_final.mp4`.

---

## 4. واجهة المستخدم وتجربة الاستخدام بضغطة زر (One-Click Automated Pipeline UI)
- **زر التشغيل التلقائي البارز:** إضافة زر رئيسي في أعلى الشاشة وفي شاشة المشروع:
  - «بدء الدبلجة التلقائية الشاملة (فصل + توليد + دمج بالفيديو)»
- **مؤشر خطوات حي وتفاعلي (5 مراحل):**
  1. قراءة الفيديو واستخراج الصوت الخام
  2. عزل الصوت البشري وتجهيز الموسيقى التصويرية
  3. توليد دبلجة مقاطع الحوار والراوي من الجيسون (Edge-TTS)
  4. تركيب المسارات الصوتية ومزامنة الخط الزمني
  5. تصدير الفيديو النهائي MP4 والماستر الصوتي WAV
- **نافذة النتائج والتحميل الفوري:**
  - مشغل فيديو للمعاينة الفورية للفيديو المدبلج النهائي.
  - زر تحميل ملف الفيديو المدبلج `dubbed_video.mp4`.
  - زر تحميل الماستر الصوتي عالي الدقة `master_dubbed_audio.wav`.

---

## خطة التحقق والاختبار (Verification Plan)
1. رفع ملف فيديو وفحص نجاح الاستخراج وفصل الموسيقى عن الحوار.
2. استيراد ملف سيناريو JSON والتأكد من توليد كافة مقاطع الحوار والأصوات المصرية تلقائياً.
3. تشغيل خط الأنابيب التلقائي واختبار عملية المكسينج وتصدير الفيديو المدبلج MP4 والصوت WAV والتأكد من التزامن الصوتي.
4. التحقق من سلامة البناء عبر `compile_applet` و `lint_applet`.
