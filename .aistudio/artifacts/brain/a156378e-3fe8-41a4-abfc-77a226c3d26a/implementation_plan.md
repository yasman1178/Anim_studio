# استوديو دبلجة الأنمي بالمصرية — قناة «محب أنمي» (Anime Dub Studio V19)

منصة متكاملة لمعالجة وسائط الأنمي ودبلجتها باللهجة المصرية بالاعتماد على مخرجات NotebookLM JSON، مع فصل مجاني للصوت عن الموسيقى داخل المتصفح، وتوليد حوارات الشخصيات والراوي عبر Edge-TTS، وبناء خط زمني متعدد المسارات، ومكتبة مؤثرات بصرية وصوتية (VFX/SFX)، وإنتاج فيديو متوافق مع يوتيوب وشورتس.

---

### مراجعة قرارات المستخدم والخيارات الحرجة (User Review & Critical Decisions)

> [!IMPORTANT]
> تم تأكيد الخيارات المحورية في مرحلة الاستيضاح الأولية، وجرى تضمينها في صلب المعمارية لتنفيذ بيئة عمل مجانية تماماً ومباشرة على الويب.

- **القرار المؤكد 1 (فصل الصوت المجاني):** تنفيذ معالجة فصل الصوت عن الموسيقى مجاناً بالكامل بنسبة 100% داخل المتصفح (Client-Side In-Browser Separation) عبر خوارزميات الطرح الطيفي والمعالجة المزدوجة (Spectral Subtraction / Phase Cancellation) المعتمدة على Web Audio API مع دعم نماذج ONNX MDX-Net الخفيفة عبر WebGPU/WASM دون الحاجة لأي خوادم سحابية مدفوعة أو اشتراكات.
- **القرار المؤكد 2 (محرك الأصوات المصرية):** استخدام محرك Edge-TTS المجاني عالي الجودة للأصوات المصرية الرسمية (مثل شاكر للراوي والشخصيات الذكورية، وسلمى للشخصيات النسائية) مع إمكانية ضبط طبقة الصوت (Pitch) وسرعة النطق (Rate) لكل شخصية وفق مصفوفة الشخصيات `character_voice_mapping`.
- **القرار المؤكد 3 (هيكل الواجهة):** لوحة عمل ستوديو موحدة (Integrated Production Studio) تجمع فاحص الفيديو وملف JSON، واستوديو فصل الصوت وعينات A/B، ومولد الدبلجة، ومحرر الخط الزمني المتعدد (Timeline)، ومستعرض المؤثرات (Asset Browser)، ومسار الرندر والنشر لقناة «محب أنمي».

---

### 1. نظرة عامة والمفهوم الأساسي (Overview & Core Concept)

- **ماذا يقدم التطبيق:** نظام إنتاجي متكامل يستورد ملفات فيديو الأنمي وملف JSON المُنتج من NotebookLM، ويفحص تكامل البيانات واللقطات والتوقيتات، ثم يفصل الصوت الأصلي عن الموسيقى مجاناً، ويولد أصوات الدبلجة بالعامية المصرية لكل لقطة، ويرتبها على خط زمني تفاعلي مع إضافة طبقات المؤثرات البصرية والصوتية مع رندر فيديو نهائي بدقتي (16:9) و(9:16).
- **الجمهور المستهدف:** فريق وصناع محتوى قناة «محب أنمي» ومترجمو ومدبلجو الأنمي العرب الراغبون في إنتاج ملخصات ودبلجات سريعة واحترافية.
- **القيمة الأساسية:** تقليص وقت إنتاج الحلقة المدبلجة من ساعات عمل يدوي شاق إلى دقائق معدودة عبر سير عمل آلي منظم يضمن دقة التوقيت، وسلامة الأصول، وجودة الصوت والمؤثرات دون أي تكاليف تشغيلية خارجية.

---

### 2. تجربة المستخدم والتصميم البصري (User Experience & Visual Design)

- **رحلة المستخدم الأساسية (Core User Flows):**
  1. **التهيئة والتحقق (Project Setup & Validation):** إدخال اسم المشروع ورابط الفيديو ورفع ملف الفيديو المحلي ورفع ملف JSON لـ NotebookLM، مع فحص فوري للمدة وتطابق اللقطات وإظهار تقرير التحقق بنقاط ملونة واضحة.
  2. **فصل الصوت ومعاينة المسارات (Audio Separation & Stem Review):** معالجة الصوت الأصلي إلى مسارين: مسار الكلام الأصلي (Vocals) ومسار الموسيقى والمؤثرات (Instrumental/BGM) مجاناً، مع مشغل A/B لمعاينة النتيجة وضبط مستوى خفض الصوت الأصلي.
  3. **توليد أصوات الدبلجة (Egyptian TTS Dubbing):** توليد التعليق الصوتي للراوي وحوار الشخصيات بالمصرية مع بيان التوقيت الفعلي وتفادي الـ Clipping مع إمكانية إعادة توليد أي مقطع منفرد.
  4. **محرر الخط الزمني المتعدد (Multi-Track Studio Timeline):** خط زمني تفاعلي يعرض مسار الفيديو/اللقطات، مسار الحوار المصري، مسار الراوي، مسار الموسيقى، ومسار المؤثرات، مع دعم التكبير والتقديم والمطابقة.
  5. **مستعرض المؤثرات والأصول المفقودة (VFX & SFX Asset Hub):** قائمة مصنفة لجميع المؤثرات (خطوط السرعة، الفلاش، الهالات، الصدمات، ضربات السيف، الانفجارات) مع تنبيه ذكي للأصول المفقودة وبدائلها البرمجية (Procedural Effects).
  6. **الرندر ومعاينة التأطير (Preview & Render Studio):** معاينة لقطة بلقطة، واختيار نسبة العرض (16:9 كلاسيكي أو 9:16 تأطير ذكي)، ثم تصدير الفيديو النهائي.
  7. **بيانات النشر واليوتيوب (Publishing Hub):** تجهيز العنوان والوصف والوسوم المخصصة لقناة «محب أنمي» مع إمكانية التصدير كملف JSON/TXT أو الرفع المباشر لليوتيوب بعد تفويض الحساب.

- **الهوية البصرية والسمات (Visual Identity & Atmosphere):**
  - **النمط الجمالي:** استوديو مونتاج احترافي مظلم وعصري (Cinematic Dark Studio Canvas) مصمم خصيصاً لساعات العمل الطويلة والدقة البصرية.
  - **لوحة الألوان (60-30-10):**
    - خلفية حيادية عميقة: Dark Slate / Obsidian (`#0B0F19` و `#111827`).
    - مساحات هيكلية وألواح عمل: Cool Surface Slate (`#1F2937` و `#374151`) بحدود رفيعة 1px خفيفة جداً.
    - لمسات تفاعلية حيوية: أحمر أنمي سينمائي (`#E11D48` / Crimson) وأزرق دقة إنتاجي (`#2563EB`) وحالة سلامة البيانات بالزمردي الهادئ (`#059669`).
  - **الخطوط والطباعة:** خطوط عربية حديثة واضحة ومقروءة (Tajawal / Plus Jakarta Sans) مع أرقام جدولية مونو (`font-mono tabular-nums`) لكافة التوقيتات والأكواد والترددات لمنع تذبذب الواجهة أثناء التشغيل.
  - **الانضباط التصميمي:** الالتزام الصارم بدستور التصميم: لا كبسولات دائرية عشوائية للميتاداتا، لا نقاط خضراء نابضة خادعة، لا ترويسات برمجية مزيفة، ومعاملة كل زر ومؤشر كأداة تفاعلية حقيقية.

### 3. القرارات التقنية والمفاضلات (Key Product Decisions & Trade-Offs)

- **القرار 1: آلية فصل الصوت المجانية بالكامل على الويب:**
  - *الخيار المعتمد:* محرك Web Audio هجين داخل المتصفح؛ يجمع بين معالجة الطرح الطيفي وإلغاء الطور الميداني (Mid/Side Spectral Vocal Cancellation & Band-pass Phase Inversion) مع خطافات تحميل نموذج ONNX MDX-Net الخفيف عبر WebGPU/WASM عند توفر العتاد.
  - *السبب:* يعمل فوراً على أي متصفح وجهاز بدون الحاجة لتثبيت برامج بيثون، وبدون بطاقة ائتمان أو سيرفرات مدفوعة، ويمنح نتيجة مجانية نقية تكفي لعزل الموسيقى وخفض الحوار الأصلي لتركيب الحوار المصري.
  - *البدائل المستبعدة:* واجهات برمجة سحابية مدفوعة (مثل Replicate أو ElevenLabs) لتكلفتها العالية على المستخدم، أو فرض تثبيت Demucs محلي معقد كشرط إلزامي للتشغيل.
- **القرار 2: محرك الدبلجة المصرية Edge-TTS:**
  - *الخيار المعتمد:* استدعاء واجهة Edge-TTS الرسمية عبر خادم التطبيق السريع مع كاش للملفات الصوتية، ودعم صوت شاكر وسلمى مع التحكم في Pitch و Rate.
  - *السبب:* أصوات مصرية طبيعية مجانية عالية النقاء وسريعة التوليد وتدعم التشكيل والنطق المصري العامي بسلاسة.
- **القرار 3: تركيب ومحاكاة المؤثرات بأسلوب Procedural Canvas / SVG / CSS:**
  - *الخيار المعتمد:* توفير مكتبة مؤثرات مدمجة برمجياً لتأثيرات الأنمي الأكثر طلباً (Speed Lines, Flash Impact, Energy Aura, Camera Shake, Vignette) بحيث تعمل وتظهر فورياً حتى لو لم يرفع المستخدم ملفات فيديو شفافة لكل تأثير.
  - *السبب:* يضمن عدم توقف المشروع أو تعطل الرندر عند غياب أصل خارجي، مع الإشارة الدقيقة للأصل كـ (Procedural Active) أو (Missing External Asset).

#### مسارات البيانات وواجهات برمجة التطبيقات (API Routes & Modules):
- `/api/tts/egyptian`: توليد الصوت المصري عبر Edge-TTS بصيغة WAV/MP3 وحساب مدة الصوت الفعلية بدقة.
- `/api/validate-json`: فحص مخطط JSON لـ NotebookLM، ومقارنة اللقطات وتوقيتات البداية والمدة وتوافق أسماء الممثلين.
- `/api/youtube/metadata`: تجهيز وصياغة وسوم وعناوين النشر التلقائية لقناة «محب أنمي».
- `lib/audio-separator`: فاحص الصوت ومحرك الفصل المباشر بالمتصفح (Web Audio Spectral Filtering + ONNX Stem Splitting).
- `lib/vfx-catalog`: مكتبة المؤثرات الإجرائية (Speedlines, Flash, Vignette, Shake, Energy Aura) والمؤثرات الصوتية الشائعة.
- `components/timeline`: محرر خط الزمن متعدد المسارات مع تحكم بمستويات الصوت (Voice, Original, BGM, SFX).

### خطة مراحل البناء والاختبار (Implementation Steps):
1. **المرحلة 1:** بناء الهيكل الأساسي للوحة العمل، وإعداد مكتبة الرموز، وتحسين سمة Tailwind باللون الداكن المخصص للأنمي واستوديو المونتاج.
2. **المرحلة 2:** تطوير فاحص ومحلل ملفات الـ JSON مع التحقق البنيوي الكامل (اللقطات، التوقيتات، الممثلين، النصوص المصرية، تحذيرات الأخطاء وتطابق المدة مع الفيديو).
3. **المرحلة 3:** محرك فصل الصوت المجاني داخل المتصفح (In-Browser Vocal Separator) مع أدوات تحكم A/B ومشغل المسارات المعزولة (Vocals & Instrumental).
4. **المرحلة 4:** مولد الدبلجة المصرية Edge-TTS مع أصوات شاكر وسلمى وتعيين الشخصيات ومراجعة التوقيت والـ Manifest لكل لقطة.
5. **المرحلة 5:** محرر الخط الزمني المتعدد (Timeline) مع شاشات المعاينة المباشرة ودعم التبديل بين 16:9 و 9:16 ومكتبة المؤثرات البصرية والصوتية (VFX/SFX).
6. **المرحلة 6:** نظام تصدير الرندر وبيانات النشر لقناة «محب أنمي» والتحقق الشامل من معايير الجودة والأداء.
